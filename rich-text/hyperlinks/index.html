    Hyperlinks

    Any text can be a hyperlink that the terminal opens when it's clicked: merge in text_link(uri), which sets link on the text_style. On a Chunk's style, that makes the chunk a link; on a Text's style, it makes all of its text one.

    LINK = text_underline | text_color("sky", 300)


@component
def root() -> Div:
    return Div(
        style=col | gap(1) | pad_x(1),
        children=(
            Text(
                content=(
                    Chunk(content="Counterweight is on "),
                    Chunk(content="GitHub", style=LINK | text_link("https://github.com/JoshKarpel/counterweight")),
                    Chunk(content=", and its docs are at "),
                    Chunk(content="counterweight.dev", style=LINK | text_link("https://www.counterweight.dev")),
                    Chunk(content="."),
                ),
                style=text_wrap_pretty,
            ),
            Text(
                content="This whole Text is one link.",
                style=pad_x(1) | border | border_lightrounded | text_link("https://pygments.org"),
            ),
        ),
    )


     Counterweight is on GitHub, and its docs are at  
 counterweight.dev.                               

 ╭──────────────────────────────────────────────╮ 
 │ This whole Text is one link.                 │ 
 ╰──────────────────────────────────────────────╯

    A link changes how nothing looks, so style it to look like one, as the example does with an underline and a color. It merges like any other field, so a Chunk inside a linked Text can link elsewhere, or merge in text_link(None) to not be a link at all.

    How terminals handle them

    Counterweight writes links as OSC 8 escape sequences, which most modern terminals support, including iTerm2, kitty, WezTerm, Ghostty, foot, GNOME Terminal and Windows Terminal. A terminal that doesn't ignores them, and shows the text as if it weren't a link.

    Clicking a link is handled by the terminal, not the app, and the app never sees the click. Counterweight turns on mouse reporting, so some terminals only open a link with a modifier held, such as Shift, Ctrl or Cmd, depending on the terminal.

    A link's URI must be printable ASCII, so CellStyle raises ValueError for anything else: a control character could end the escape sequence and start another. Percent-encode anything outside ASCII, as urllib.parse.quote does.
