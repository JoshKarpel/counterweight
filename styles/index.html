    Styles

    Merging

    Styles are merged using the | operator: left | right. Every field starts out unset (the counterweight.styles.UNSET sentinel), and the result takes right's value for every field right sets, and left's value otherwise.

    A field set to its default value is still set, so it overrides left. CellStyle(bold=True) | CellStyle(bold=False) is CellStyle(bold=False), border | border_none draws no border, and text_justify_center | text_justify_left justifies left. Utilities set only the fields they are about, so they layer without clearing each other: text_color("red", 500) | text_bg("slate", 900) is red text on a slate background.

    merge does the same for any number of Styles: merge(a, b, c) is a | b | c. It skips None wherever it appears, so a style that only sometimes applies can be passed inline, as in merge(base, hover_style if hovered else None), and merge() is an empty Style().

    Nested styles merge field by field too: Style(text_style=CellStyle(bold=True)) | Style(text_style=CellStyle(italic=True)) is both bold and italic. layout follows the same rule, field by field.

    When an element is drawn, any field still unset takes its default from STYLE_DEFAULTS and CELL_STYLE_DEFAULTS.

    How an element is laid out and drawn.

    Every field except layout starts UNSET, and the nested border_style and text_style start as empty CellStyles. Merging with | takes the right side's value wherever it is set, including when it is set to the default, so border | border_none has no border. layout merges the same way, field by field. Unset fields resolve to the defaults in STYLE_DEFAULTS.

    A border side is drawn where its width in layout (border_top, ...) is 1, and border_kind chooses the characters it's drawn with. A border_kind of None removes the border, along with the space reserved for it. Each side is one cell, so a Style whose layout sets a border width other than Length(0) or Length(1) raises ValueError.

    clip_to chooses what clips the element. With "padding", the default, or "border", it's its parent's padding or border box, on each axis where the parent's overflow is Hidden, Clip or Scroll, and every clip above the parent clips the element too; "border" lets a title be drawn on its parent's border. With "screen", the element is unclipped: no ancestor clips it, so a popup can reach past them, though its own overflow still clips its descendants.

    overflow_anchor and stick_to_end_x and stick_to_end_y choose how a scroll container's offset follows its content when the content changes. With overflow_anchor "auto", the default, a scroll container keeps the content in view where it was, as CSS's overflow-anchor does; with "none", a scroll container keeps its offset, and nothing inside an element that sets it is an anchor for the scroll container around it. A scroll container that sticks to its end on an axis and is scrolled to its end there stays scrolled to its end when its content grows.

    counterweight.styles.merge 

    merge(*styles: Style | None) -> Style

    Merge styles left to right, the same as chaining them with |.

    Later styles win wherever they set a field, and Nones are skipped wherever they appear, so a conditional style can be passed as hover_style if hovered else None. With no styles, or only Nones, the result is an empty Style().

    counterweight.styles.IndexedColor dataclass 

    IndexedColor(index: int)

    Entry index, from 0 to 255, of the terminal's palette, whose color the terminal decides, as the SGR sequences 38;5;n and 48;5;n name it.

    Entries 0 to 7 are black, red, green, yellow, blue, magenta, cyan and white, and 8 to 15 their bright forms, all of which the user's theme sets; 16 to 231 are a 6x6x6 color cube and 232 to 255 a gray ramp, which terminals define as xterm does. Where no terminal decides, as in a screenshot, it's drawn as DEFAULT_PALETTE[index]. An index outside the palette raises ValueError.

    counterweight.styles.TerminalDefault dataclass 

    TerminalDefault()

    The terminal's default color, which the user's theme sets: its default foreground where it colors text (SGR 39), and its default background where it fills one (SGR 49). Where no terminal decides, as in a screenshot, it's drawn as white text on black.

    Every TerminalDefault is equal, so use TERMINAL_DEFAULT.

    How to draw a cell's character: its colors and attributes.

    Every field starts UNSET. Merging with | takes the right side's value wherever it is set, including when it is set to the default, so CellStyle(bold=False) turns bold off. Unset fields resolve to the defaults in CELL_STYLE_DEFAULTS.

    link makes the cell a hyperlink to that URI, which the terminal opens when it's clicked (an OSC 8 hyperlink); None makes it not a link, overriding a link it would otherwise inherit. The URI must be printable ASCII, so percent-encode anything else, or CellStyle raises ValueError.
